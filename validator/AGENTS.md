# validator/: agent notes

**Package:** `sudoku_validator`, stdlib only. It is the leaf of the dependency graph and must never import `sudoku_generator` or web/DB libraries. The public API is everything exported from `src/sudoku_validator/__init__.py`, which is the contract in PLAN.md §5.1 and §5.5.

## Layout
- `grid.py` (parse/format, units/peers), `solver.py` (bitmask + MRV backtracking, `count_solutions`), `state.py` (candidate state)
- `techniques/`: one module per family; `logical_solver.py` applies them in level-then-weight order
- `rating.py` (`rate()`, `Difficulty`, `TECHNIQUE_LEVEL`), `hints.py` (`next_hint`), `report.py` (`validate_puzzle`)
- `search.py`: `propagate()` and `find_contradiction()` for search mode

## Conventions and pitfalls
- **Technique names** are display strings ("Naked Single", "X-Wing") and serve as the keys of `TECHNIQUE_WEIGHTS`. The backend and frontend show them verbatim.
- **Level is decided by the hardest technique.** `BEGINNER_MAX_SCORE = 42` is the only score-band rule. The 60 → 42 change and the rebalanced level mapping were measured on 1,000 random puzzles (see PLAN.md §4).
- **Unique Rectangle** is enabled only once uniqueness is proven. `rate()` on a puzzle with several solutions returns `difficulty=None`.
- **Chain searches are bounded:** X-Chain ≤ 11 links, XY-Chain ≤ 8 cells, ALS ≤ 4 cells, forcing chains ≤ 24 placements. Keep `rate()` p95 under 100 ms.
- **Hints:** when `value` is set, `cells[0]` is the target cell. Elimination-only steps look ahead to the placement they unlock. Errors are reported first.
- **Contradiction order** is part of the contract, because the frontend mirrors it:
  - kinds: duplicate, then no_candidates, then digit_nowhere;
  - units: rows, then columns, then boxes, ascending;
  - candidates are peer-based only.
- **Shared fixture:** `tests/fixtures/contradictions.json` is generated by `tests/contradiction_cases.py`, and the frontend tests against it. Regenerate it with `uv run python validator/tests/contradiction_cases.py`. A test fails if it is stale.
- **Errors:** grids with the wrong shape raise `ValueError`; `validate_puzzle` never raises.

## Verify
`./scripts/verify.sh --only validator`. Benchmarks: `uv run python validator/benchmarks/bench.py`.
